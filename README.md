# 🦢 白鷺祭用語集 & キャンパスマップ (Shirasagi Festival Glossary & Map)

**「PDFの用語集をもっと使いやすく。」**

大阪公立大学 学園祭「白鷺祭（しらさぎさい）」実行委員会向けの、用語検索およびキャンパスマップWebアプリケーションです。
従来PDF形式で配布されていた用語集をWebアプリ化し、スマホからの検索性向上、キャンパスマップとの連動、そして知識の属人化解消を目指して開発されました。

🔗 **Sample Demo**: https://shirasagi-sai-sample.vercel.app/

*(※デモ版はセキュリティの都合上、本番データではなく `sampledata.json` のダミーデータを表示しています)*

---

## ✨ 主な機能 (Features)

* **🔍 リアルタイム検索**: 用語名、読み仮名、関連キーワードからインクリメンタルサーチが可能。
* **🏷️ マルチタグフィルタリング**: 「情報部」「機材」「場所」など、複数タグの掛け合わせ検索に対応。
* **🗺️ インタラクティブ・キャンパスマップ**: 「場所」に関する用語は、地図上のピンと連動。ピンをタップして詳細を確認したり、リストから地図上の位置へジャンプすることが可能。
* **⭐ お気に入り機能**: よく使う用語をローカルストレージに保存し、トップページから即座にアクセス。
* **🔒 セキュアな運用設計**: 内部の機密データ（スプレッドシートのURL等）をソースコードから完全に分離。GitHubをパブリック公開しつつ、情報漏洩を防ぐセキュアな構成を実現。

## 🏗️ システム構成とセキュリティ (Architecture & Security)

本アプリは、フロントエンド(ブラウザ)とバックエンド(Node.js API)を分離し、**1つのソースコード（GitHubリポジトリ）から「本番環境」と「サンプル環境」を安全に作り分ける構成**を採用しています。

### 🛡️ バックエンド(Node.js)による機密情報の隠蔽
データの取得には Vercel Serverless Functions 上で動作する **Node.js API (`/api/sheet.js`)** をバックエンドとして経由します。これにより、フロントエンドのブラウザから直接スプレッドシートのURL（機密情報）が見えることを防いでいます。

###  環境の自動切り替えロジック
* **本番環境 (実行委員専用)**
  * Vercelの環境変数 `CSV_URL` に本番用スプレッドシートのURLを設定してデプロイ。
  * Node.js APIが環境変数を検知し、裏側でスプレッドシートから最新のCSVデータを取得してフロントエンドに返します。
* **サンプル環境 / ローカル開発環境**
  * Vercelの環境変数を**空**にしてデプロイ（またはローカルで起動）。
  * Node.js APIが環境変数が存在しないことを検知し、自動的にリポジトリ内のローカルダミーデータ (`sampledata.json`) を読み込んで返します。

これにより、**コード上に機密情報を一切含めずにポートフォリオとして一般公開**することが可能になっています。

## 🛠 技術スタック (Tech Stack)

フレームワークに依存せず、軽量かつ高速に動作する **Vanilla JS** 構成をベースに、サーバーレス関数を組み合わせています。

* **Frontend**: HTML5, CSS3, JavaScript (ES6+ Vanilla)
* **Backend (API)**: Node.js (Vercel Serverless Functions)
* **Data Source**: Google Sheets (本番) / JSON (サンプル・ローカル)
* **Libraries**: PapaParse (CSV解析)
* **Infrastructure**: Vercel

## 🚀 開発環境のセットアップ (Local Development)

ローカル環境では環境変数がないため、安全なダミーデータ (`sampledata.json`) を使用して開発を行います。

### 手順 (VS Codeを使用する場合)

1. VS Code に拡張機能 **Live Server** をインストール。
2. `index.html` を開き、画面右下の **"Go Live"** ボタンをクリック。
3. ブラウザが立ち上がり、ローカル環境でアプリが起動します。（自動的に `sampledata.json` が読み込まれます）

※APIの挙動（スプレッドシートとの通信）を含めてローカルでテストしたい場合は、[Vercel CLI](https://vercel.com/docs/cli) をインストールし、`.env` ファイルに `CSV_URL` を設定した上で `vercel dev` コマンドで起動してください。

## 📝 本番データの更新フロー (実行委員向け運用)

実際の用語データの追加・修正・削除は、指定された**管理用Googleスプレッドシート**で行います。

1. **スプレッドシートを編集する**
   * 行を追加・編集するだけで即時保存されます。
2. **反映を確認する**
   * アプリをリロードすると、Vercel APIを経由して最新の内容が反映されます。
   * *(※Google側のキャッシュ等により、反映まで最大5分程度かかる場合があります)*
